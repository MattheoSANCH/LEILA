==============================

une, il suffit de deposer un nouveau fichier ICI en gardant le meme nom :
le site le recupere tout seul, il n'y a rien a modifier dans le code.

FORMAT
------
JPG, environ 1200 a 1600 px de large, moins de 500 Ko.
Photos prises de jour, sans flash. Cadrage un peu large : le site
recadre automatiquement selon la taille de l'ecran.

POUR ALLER PLUS LOIN (facultatif)
--------------------------------
Les douze emplacements sont remplis, le site est complet.
Si un jour vous voulez l'enrichir, deux photos ajouteraient beaucoup :
la devanture depuis la rue, et le patissier derriere le comptoir.
Ce sont celles qui donnent un visage au commerce.

MODIFIER LES HORAIRES
---------------------
Ils apparaissent a DEUX endroits qu'il faut changer ensemble :
1. le tableau affiche, section « Infos pratiques » de index.html ;
2. le tableau HORAIRES dans le JavaScript, tout en bas du fichier,
   qui calcule le « Ouvert / Ferme » en direct.
Les deux sont signales par un commentaire dans le code.

SI UNE PHOTO MANQUE
-------------------
L'emplacement affiche un visuel de substitution discret. Le site
n'affiche jamais d'image cassee.

ESPACE CLIENT
-------------
La page espace-client.html permet a la boulangerie d'envoyer ses
demandes de modification. Son adresse n'apparait nulle part sur le site.

AVANT LA MISE EN LIGNE :
1. Changer le code d'acces : chercher CODE_ACCES dans espace-client.html.
2. Apres le deploiement, dans Netlify :
   Site configuration > Forms > Form notifications > Add notification
   > Email notification, et indiquer VOTRE adresse mail.
   Sans cette etape, les demandes arrivent dans le tableau de bord
   Netlify mais ne sont pas envoyees par mail.

Le code d'acces n'est PAS une securite : il est lisible dans le code
source. Il tient les curieux a l'ecart, rien de plus.
